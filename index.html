Cara ikut

  1. Punya Agent ID (.ai) — klaim di aplikasi Binance: Wallet → banner Agent ID.
  2. Klik Connect Wallet (Binance Wallet / wallet browser apa pun). Pastikan di BNB Smart Chain.
  3. Klik Check-in hari ini dan konfirmasi di wallet kamu. 1 check-in per hari (hari UTC).
  4. Check-in tiap hari tanpa bolong biar streak naik. Bolong sehari → streak reset ke 1.

Kontrak: —

Keamanan & privasi. Halaman ini file statis — tidak ada server, tidak ada database, tidak ada sesi yang disimpan. Check-in hanya terjadi saat kamu klik tombol dan konfirmasi sendiri di wallet — tidak ada transaksi otomatis. Kontrak tidak pernah menerima atau menyimpan dana (tanpa fungsi payable).
